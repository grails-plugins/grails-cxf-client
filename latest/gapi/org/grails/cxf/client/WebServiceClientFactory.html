        Get a web service client. This should be invoked at startup to get a web service that can be injected into all classes that depend on the web service client interface.

        Parameters:
        clientInterface - The interface the web service must implement (this is what will be injected into other classes).
        serviceEndpointAddress - Url for the service endpoint
        secured - Indicate if the web service needs to be secured using digital certificate authentication (true) or if it is does not require the certificate usage (false), which is the default.
        username - Username to use for secured clients. Ignored if secured is false.
        password - Password to use for secured clients. Ignored if secured is false.
        Returns:
        The web service client. The returned object will proxy the clientInterface (allowing it to be injected into other classes as the interface).
